# AI Search Provider MariaDB

Store AI Search embeddings in MariaDB and search them by similarity. Use this backend when Backdrop’s active database connection uses MariaDB 11.7 or later.

## Installation

Enable AI Search and configure an embedding model. Choose **MariaDB Vector** when creating a Search API server. [Backdrop module installation guide](https://backdropcms.org/user-guide/modules)

[Setup and troubleshooting](https://github.com/backdrop-contrib/ai_search_provider_mariadb/wiki)
